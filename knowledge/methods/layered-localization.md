# 分层图片本地化：五阶段

状态：active。来源：用户明确授权的通用执行流程；技术适配仍须逐图验证。适用于单张图片的翻译与视觉还原，不承诺任意图种均已实现自动处理。

执行入口见 [单图工作流](../../agent/workflows/single-image.md)，选路见 [内容路由](content-routing.md)，样式设计见 [文字构图](typography-composition.md)。阶段记录是可复查证据，不因文件名或 quality 输出存在就成立。

| 阶段 | 必须输出 | 必须实际观察与停止条件 |
| --- | --- | --- |
| 1. 语义与样式提取 | 区域原文/译文/保留理由、保护对象、疑点；样式计划或等价阶段记录，包含层级、容器、字形比例、字重、行宽、弧度/透视、光照和路线依据 | 打开全图、100%及必要局部，记录可见事实；分清源图观察、设计推断和待验证假设。原文/对象/要求不清时保留 pending，不凭空补字。 |
| 2. 背景单独去字审核 | 无目标文字的底图、编辑范围/蒙版、所用方法与输入哈希、单独背景审核观察 | 在添加译文前打开底图，对照原图检查残字、纹理、容器曲线、金边、接缝、人物与保护对象。失败先修背景，禁止靠新字遮丑后宣布自然还原。 |
| 3. 独立透明目标字层 | RGBA目标字层、字体与实际布局参数、效果与语义类型记录；透明/对比底预览 | 单独打开文字层，再按目标尺寸检查字形、缺字、字距、线宽、立体效果和曲线。透明文件存在不证明正确；若弧形/透视要求无法实现，换路线或 pending。 |
| 4. 合成 | 与原画布对齐的合成图、参与文件哈希、保护范围检查与阶段观察 | 查看文字与容器是否一起成立：行宽比例、上下留白、轮廓、光照、视觉重心；范围外像素检查可辅助保真，但不能替代肉眼检查。 |
| 5. 全图适配审核 | 当前输出绑定的审核记录、问题清单、技术/Agent/用户三种结论 | 全图缩略看层级与张力，100%看真实可读性，局部放大看残字/描边/接缝。逐区及全图记录观察；最新用户反馈未解决不能称完全验收。 |

基础 CLI 当前只支持矩形横排的 solid/clean_plate 渲染，可能在同一命令内修背景并排字。新增 [分层配置工具](../../docs/layered-tools.md) 已提取常见采样修复、独立倾斜文字、素材合成和检查导出；优先每图配置，文字修改复用背景，另建渲染版本。未知复杂纹理、弧形/透视造型仍需按图选实际工具。工具不自动识图或代替阶段观察；不要每图重写已有操作，也不擅自给旧manifest添加未实现字段。以 [架构合同](../../docs/architecture.md) 和实际回执为准。

工具按视觉需求选择：局部源像素重建、矢量容器重建、真实原图编辑工具、脚本/模型辅助样式设计可组合使用。输入能力与授权按当前会话真实合同确认，不能把只有文字输入的生成接口当成参考图编辑。摄影背景的工具核实、独立背景审核及合成退化检查统一见[摄影图修复](photographic-background-repair.md)；支持参考图不等于输出通过，个案授权不能推成常驻付费授权。

每阶段记录查看了哪个实际文件、尺寸/缩放、具体区域、看到了什么、缺陷与决定。文件修改后更新哈希并重新审看受影响阶段；历史失败、旧审核与旧 pass 保留，不能自动升级成满足新视觉要求的 pass。
