# 按内容选路

状态：provisional。这些是需在当前图验证的技术候选，少量缎带案例不能证明各分支均已成功。通用阶段见 [分层流程](layered-localization.md)。同一图片可逐区混用路线；不得把一个分支条件泛化到全图或所有图片。

| 分支 | 适用与候选方法 | 不适用与保护要求 | 失败与停止条件 |
| --- | --- | --- | --- |
| 平色 UI、按钮、标签 | 实际均匀背景可用 solid；标准矩形横排可用基础 CLI。检查像素和肉眼观察再决定颜色、边距与对齐。 | 渐变、半透明、阴影/图标穿过的区域不能按平色覆盖。保护图标、控件边缘、状态与数值。 | 有补丁、被吞边框、缺字、最小可读字号放不下时调整区域/文案/路线，不无限缩字。 |
| 渐变容器、缎带、装饰标题底面 | 可按真实结构局部源像素重建或矢量容器重建，再单独审核底图；需要时使用真正编辑工具。 | 不声称恢复了原字遮住的未知纹理；保持轮廓、金边、高光、装饰和层次。只在几何/纹理足以推断的局部使用重建。 | 重复纹理、断边、过度平滑、光照错位、遮住人物/花朵时停止该候选；需改善证据或换工具。 |
| 复杂摄影、人物、产品 | 有可信邻近源像素才做局部重建；复杂遮挡优先真正的原图编辑工具，生成结果逐项对照。 | 不把任意克隆或新生图当隐藏细节复原。保护脸、手、产品结构、品牌与真实场景关系。 | 无可靠源像素且无真正编辑能力，或重建损伤主体时 pending；不能一律称只能外部编辑，也不能硬修后 pass。 |
| 弯曲、透视、立体艺术字 | 先提取基线/字轴/透视和光照，再选逐字沿曲线、矢量路径、透视变换、脚本或模型辅助设计；透明层独立核字。 | 基础 CLI 不自动识别弧形，也不自动实现这些变形。保护字形可读性和容器关系，避免非等比强拉字。 | 弧度不足、透视方向错误、立体光源不合、文字拼错或张力明显弱时返工；无可验证实现保持 pending。 |
| 密集文档 | 优先忠实读序、完整语义、字号与列布局；分块处理，必要时设计稿/矢量工具重排。 | 不套用装饰标题的曲线和大字逻辑。保护脚注、页码、表格归属及限制条件。 | 小字不可辨、密度过高导致不可读、漏段时先解决来源或布局，不靠模型猜字。 |
| 图表、数据表 | 识别轴/图例/单位/标签与数据关系，分别重排并逐数核查。 | 保护点位、刻度、线条、颜色编码、数值关联；不能只换文字破坏数据含义。 | 标签错配、遮住数据、单位改变或无法确认原数值时停止相关区域。 |
| 漫画、气泡 | 先确认对话者、气泡读序、语气与拟声词，再按气泡形状分行。 | 不把普通广告的行宽规则照搬；保护角色、气泡尾、画格边界与必要的拟声风格。 | 说话对象错、读序变、气泡越界、语气失真时返工。 |
| 竖排、RTL及混排 | 使用支持对应书写方向、字形塑形和标点规则的真实排版能力，先做小范围验证。 | 基础横排 CLI 不能证明支持竖排或 RTL；保护数字、括号、连字、姓名和标点顺序。 | 字序错误、断连字、标点方向或列序错误时停止；换排版引擎或 pending，禁止用翻转图片代替正确排字。 |

任何路线都须通过 [背景、字层、合成和全图审核](layered-localization.md)。设计参考只提供候选，不是去字证据；没有证据不 pass。
