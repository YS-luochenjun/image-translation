# 336×280 节日缎带本地化案例

日期：2026-10-29。最新用户反馈：**认可当前推荐版的效果**，原话“挺好的，请你进行知识沉淀与总结”。[反馈记录](user-feedback.json) 绑定输出哈希。案例仍为 **partial**：表示仅覆盖一个样例并保留已披露构图取舍，不再表示旧版张力、弧形、行宽问题尚未处理；具体技术方法仍需逐图验证。

适用范围：小尺寸、少量装饰性标题、可调整的缎带/容器。不能推广为人物摄影上的任意擦字、密集文档、商标或所有艺术字都适用。

## 迭代与用户反馈

1. **首版失败**：矩形红块遮英文，破坏原缎带边界和明暗。用户指出效果不好。
2. **分层改善**：先做空白缎带，再加金色宋体透明层。用户认可比首版好，但指出张力弱、弧形不足、上短下长和整体协调不足。
3. **艺术字重设计**：一次文本生图生成金色重体字与红缎带复合资产，本地合成保留照片。上行“轻触这朵玫瑰”，下行“看看谁爱你”，保持互动含义，不增加“最爱”等新承诺。比较A/B/C后推荐B，最后下移1px保护玫瑰邻近像素。
4. **最新反馈**：用户在看到本轮推荐图与构图取舍说明后评价“挺好的”。这支持当前图的设计方向与视觉效果，不代表像素级复原、可编辑字体、任意图种通用或后续付费调用的常驻授权。

模型只收到了文字提示，没有见原图，不属于原图编辑；生成的是文字与容器一体的复合RGBA栅格层，不是可编辑纯文字层。原始模型资产、尺寸方案、局部观察与输入/输出哈希均有记录。

## 已观察的取舍与失败路线

- B的重体窄字、金属倒角、逐字倾斜与拱弧，明显比普通宋体更有张力；上下行与宽上带/窄下带一起设计，获得用户正向反馈。
- A在两肩后方露出少量旧平直容器；C形成明显双容器，不选作成品。新面片透明不代表旧容器已经清理。
- B字带上移覆盖少量白衣下沿及心框底尖，属于已披露的构图变化。面部、上方场景与声明的玫瑰核心ROI保持；不能写所有非文字像素都未变。
- 336px下“触”“瑰”等密笔有亮边/暗影粘连，两侧交界略硬。制作Agent和独立Agent实际看图确认文字可读、未见明确错字或英文残留，不等于字体文件级笔形校验。

## 可迁移的方法

先辨别问题属于语义、背景、字形、容器还是整体构图，再换对应方法。常规字体清晰但张力不足时，不应只反复调字号；装饰标题可比较生成式图形资产路线。译文在含义不变的前提下重分行，容器随目标语言一起设计；不能为凑行宽新增事实。候选必须在同一原尺寸全图里比较，再核对放大局部。

通用方法见 [五阶段流程](../../methods/layered-localization.md)、[条件选路](../../methods/content-routing.md)、[文字构图](../../methods/typography-composition.md)。本例的6/5字、红金材质、上长下短、尺寸与位置均不成为其他图片默认参数。
