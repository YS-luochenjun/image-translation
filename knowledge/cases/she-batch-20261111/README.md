## 可迁移的经验

**相似广告逐源识读。** 025源1是“经常未察觉、超过60、说出全部12个名称”，源2是“1960年代、如今大多数人叫不出名称”，源3是“超过65、12件事、大脑年龄”，源4是“61至79、凭记忆说出全部12个名称”。这些条件不能用同主题模板覆盖。031源1英文写的是“被听见的机会”，与025同厨房人物的“叫出物品名称”不同；保持当前原文，不凭画面替换成更合理的另一条文案。

**字形必须实际成形。** 本机Pillow RAQM不可用，本轮worker用Chromium Canvas绘制阿语、印地语和泰语透明文字层，逐语检查连写、RTL内数字、元音和组合字。字体存在、测量有宽度都不足以证明正确；该路线仍是宿主执行脚本的案例，不表示基础CLI已自动获得复杂文字能力。

**最终编码是新审核对象。** 023部分纹理PNG超当次150KiB上限后转JPEG；源7西语300×250又在明确的远程取图失败后换最终JPEG，旧PNG审核仍保留。按最终SHA选择当前有效审核，保留旧版本，不用“有审核文件”替代当前字节证据。快照保存这一个成员的旧/新SHA与现行审图摘录；未把取图失败直接归因为格式错误。
