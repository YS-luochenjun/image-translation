# 双语古典海报：字平、阴影漏检与主动复盘

日期：2026-10-30。案例状态partial。用户指出旧版字平、阴影不足；修订后反馈“目前确实好了一些”，仅认定相对改善，不标完全验收。证据和原话见 [反馈](user-feedback.json) 与 [文件哈希](evidence-manifest.json)。

## 输入与语义

[源图](evidence/source.png) 为300×250葡语海报，规范化PNG SHA256：`f5c1fad0cd3665a920a01a28050f9d0fe2f204bd609d522422fc1d0b2b77f861`。

原文：Toque no Quadro para Ver Sua Verdadeira Personalidade。中文定稿“轻触画框，看看你的真实个性”；日语“額縁をタップして、本当の性格を見てみよう”。quadro指有框画像整体，不是镜子；personalidade指个性/性格，不能改成面貌。中日自然断行不机械照搬葡语六行。

## 实际阶段与缺口

1. 实际读取源图和4倍查看图，核对葡语与双语语义。
2. 单独去除葡语及原阴影，以观察到的无字墙面色调和纹理重建右侧区域，实际检查底图。人物、雕花框与街景保留；墙面细纹是近似重建，竖向更规整，不是找回被遮住的原始纹理。
3. 独立制作目标字层，使用对应语言的Noto Serif CJK粗宋/明朝字体。
4. 复用现有工具合成并检查保护区。
5. 自审和另一Agent确实看过图，并记录版本哈希，旧版仍被宽松判为可交付。

因此，不能称没有执行分阶段，也不能将存在阶段文件解释为还原成功。**实质缺口是样式提取没有转成足够具体的目标和可失败的比较标准。**

## 旧版为什么仍被放行

[旧中文](evidence/chinese-before.png) 与 [旧日语](evidence/japanese-before.png) 使用较均匀的金色面与约(1,1.3)px偏移的深色实字，偏移很窄、没有柔影衰减。记录中审核主要称“金色衬线和短影可接受”，重视文字完整、断行、可读性、主体保留，却未充分比较原图的厚字面、贴根暗部和右下墙影。

[旧独立审核](../../../runs/trueself-bilingual-20261030/independent-review.json) 证明有另一身份参与，不证明视觉标准已经充分。用户看到旧图后明确指出阴影不足、字体偏平；本例说明共享宽松标准会让自审和独立复核同时漏检。

为什么用户能指出：可确认其反馈针对原作与成图的整体深度差异；“用户直接感知平面感而不需要参数知识”是合理解释，不能冒称了解其实际思维过程。Agent并非完全不知道阴影，而是把“加过短影”误当成“相对原图已足够”。

## 修订改变的是文字层，不是去字背景

[修订中文](evidence/chinese-revised.png)、[修订日语](evidence/japanese-revised.png) 与旧版共用 [无字背景](evidence/clean-background.png)，文件SHA256保持 `bff7177452189b6b766262debc74e96944acc5a3707a6e37969156e926588b34`。未重擦人物/墙面，译文未变。

独立字层增加：稍实的字面、贴根接触暗边、浅暖色暗边、右下柔化投影、克制的暖金亮度变化。效果参数以最终300×250像素为单位；投影候选偏移(1.7,2.8)、模糊1.15是本图取值，不能当通用默认参数。日文字块为容纳边缘左移约1.5px。

字效不是直接从源图提取可编辑字体文件，而是根据观察用真实本地字形和效果重建；没有imagegen调用。复杂字腔、裁切、粘连、脏晕和主体保护重新实看。新的独立视觉结论为“实质改善，可交付修订候选、待用户验收”，并未证明完全一致。

[同尺度对照](evidence/comparison.png)：上中文、下日语；各行从左至右为源图、旧版、修订。两版主体和左182列检查保持原像素；统计不能代替实际视觉比较。

## 状态与仍在的限制

- 技术：两版修订生成及哈希/保护检查通过。
- Agent视觉：原尺寸和放大复核确认字面、投影有可见改善；不是原图字体完全复刻。
- 用户：只确认“好了一些”，没有逐语言最终验收，也没有说每个视觉维度都满意。
- 已知差异：中文四行、日语五行仍比葡语六行疏；CJK字形与源拉丁字结构不同；右侧壁面纹理为近似重建。不能把所有差异都归入无条件可接受，也不能擅自改义填空。

## 可复用与禁止泛化

采用 [差异驱动自检](../../methods/visual-fidelity-self-review.md)：先从源图提出关键视觉要求，再以同尺度对照寻找缺口；发现问题自主回到相关层，复审效果与退化，保留版本证据。不要等用户提出“阴影不足”才把原有风格要求当硬目标。

脚本适合精确文案、常规字形和可控制的效果；当造型或材质超出现有字体/工具表达能力时，再评估模型或设计素材。不能把本例概括为“以后都加大投影”“所有金字用本参数”“只要多找Agent就会发现”“脚本总比模型好”或“一定第一张就完美”。
