## 输入与方法

输入336×280 JPEG，文件标签包含“方图”，以实际画布336×280处理，不强行裁为正方形。规范化PNG仅更换容器，原输入未改；[源图](evidence/source.png) SHA256为 `dd2ed34fd1c7d45d68bb9c33193e67ea92020d3fa07605142944ebb84e727ca9`。

按五阶段执行：实际读取全图与放大小字；单独制作去字背景；用微软雅黑粗体生成透明中文层；比较“免费”和“免费领”两版；实际复核全图及局部，独立Agent再核义与观察。没有调用图像生成，没有重画食品或logo。

## 角色判断与定稿

| 原文/对象 | 处理 | 理由 |
| --- | --- | --- |
| 顶部BURGER KING字标、品牌logo、杯身和薯条盒logo | 保留原像素 | 品牌身份和包装图形，不是普通标题 |
| Whopper® | 皇堡® | 本例适用的产品名称译法，注册标记保留 |
| FREE / COUPON 2026 | 免费领 / 2026 优惠券 | 三字标题保持原横向分量，不增加券字重复，年份不变 |
| Treat Yourself Today! | 今天就犒劳自己！ | 保留轻快语气 |
| LIMITED TIME OFFER! | 限时 / 优惠 | 不补“仅限今日” |
| Get / Med. Fries / Med. Drink / FREE! | 享用 / 中份薯条 / 中杯饮料 / 免费！ | 保留两种中份规格和免费含义；首稿“即享”改为“享用”，避免添加即时性 |
| Claim Free Meal | 领取免费套餐 | 不补无需消费、人人可领等条件 |
| Subject to qualifying conditions | 需符合领取条件 | 资格条件不能当版权或改成别的规则 |
| 右下ChoiceInsiders与购物袋图标 | 保留原像素 | 发布标识；原图没有版权句，不发明©或版权声明 |

## 视觉与修复经验

- 保留红黄白配色、大红标题、皇堡与免费双重强调、红按钮和食品重心；没有套用前例的红金艺术字。
- 白背景直接在观察到的空白区去字，黄色/红色内部按附近真实色彩取样。初期只去深色像素会留下JPEG浅色文字残影，改为修复文字内部，再独立看无字背景。
- 保留原笔刷外轮廓、两红皇冠、两白皇冠、黄板分隔线和红强调线、按钮与旗标轮廓、虚线边框。最终文字alpha曾触及皇冠ROI四个边缘像素，局部清理后重审，“享用”字形完整。
- 产品与标签边界不是矩形：标题组矩形会碰面包角的空白位置，增强脚本以实际ROI检查保护面包与其余照片，不把合同假冲突理解为允许覆盖商品。
