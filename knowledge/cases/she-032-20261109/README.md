# SHE-032摄影去字：旧暗带否定与清晰底图认可

日期：2026-11-09。案例状态partial：用户明确认可新去字底图，最终28张多语排版尚未获得用户整体验收。新版已完成自审、上传入库、原需求绑定及fresh下载SHA256核验，之后才修改项目规则。

## 反馈与问题

用户指出旧版“为什么你做出来，有一个遮罩呢”，要求重做。旧版在女孩裙子、草地与路面的文字区域叠加宽羽化暗化，产生明显暗灰带。旧自审88.1分把这一问题当成minor，判断过宽；该pass保留为历史，不能证明旧版满足当前要求。

用户看过新去字图后说：“这张图片的去字很好。请你在项目中，增加，不要之前的遮罩，要更好的效果。（等你实现并上传完成后，就进行修改项目）”。[反馈记录](user-feedback.json)分别绑定旧版、新生成底图、实际用于排版的底图和最终文件哈希。

## 处理与实际观察

使用当前内置图像工具的真实参考图输入能力，以原图去除正文及按钮。原图的女孩身份、动作、旧车和复古黑白照片保持可辨；未知衣褶和路面只作自然补全，不声称恢复被文字遮住的原始像素。没有另调外部收费CLI/API。

高分辨率去字图获用户正向反馈。实际336×280底图缩小后保留原图顶部67行，在67至76行间局部衔接，保留脸部及上方汽车；这一局部衔接不构成正文区暗带。独立查看底图时，裙褶、双臂、膝盖、草地和道路纹理自然连续，无新增暗板或模糊带。各语使用独立透明文字层及原风格橙色按钮，字形描边提供对比。

14语：zh-TW、es、pt、fr、th、pl、tr、hi、ar、it、vi、ko、ja、nl；每语336×280、300×250，共28张。逐语言查看文字层和两种原尺寸成图，另开ar/hi/th小尺寸及ko大尺寸检查。审核身份self，评分92.5；不冒称母语认证或独立审核。

## 执行效率与工具边界

本次摄影PNG超过按钮字节限制，改用高质量JPEG，终审与上传以JPEG的SHA为准；压缩前的PNG通过不能代替JPEG审核。复杂文字使用Chromium塑形及独立字层，仍逐语看小尺寸成图。方法分别回收到[尺寸规划](../../methods/source-set-and-size-planning.md)和[文字构图](../../methods/typography-composition.md)，不把需求专用渲染脚本设成所有素材的默认模板。
