# 图片翻译素材 Tag 约定

按用户2026-11-11说明，Tag主要用于方便人在素材库搜索。需求怎么提就怎么标，不建立严格的标签分类或额外交付门禁。适用于长方竖图image和大按钮button。

## 打什么

| 内容 | 做法 | 例子 |
| --- | --- | --- |
| 翻译语种 | 上传时带上该素材对应的目标语种，沿用需求里的写法；语言代码即可，不要求中文名称 | `ja`、`hi`、`es`、`jp` |
| 尺寸 | 明确要求尺寸的，建议带上，尤其是大按钮；标当前素材实际包含的尺寸，方便筛选 | `300x600`、`336x280`、`300x250`、`970x250` |
| 产品或主题 | 信息明确时加一两个便于搜索的词，优先复用已有合适标签 | `spotify`、`Dementia Test`、`fruit` |
| 需求编号 | 面板任务建议保留，方便从需求找到素材 | `SHE-20261111-025` |
| 其他 | 已有合适标签继续保留；`图片翻译`、`source-4`等按实际需要使用 | 不强制每条补齐全部类别 |

单语素材只打自己的目标语种，不把整单的所有语种都贴上去。需求中`jp/kr/vn/id`等是多个目标语种时，按各成品分别标。没有明确语言写法时采用项目已有语言映射，不从保留的品牌英文推断目标语种。

需求写`336*280、300*250`时，单张336×280的素材可标`336x280`，单张300×250可标`300x250`；同一素材记录确实包含两种尺寸时才同时标两种。`*`、`×`、`x`都能表达尺寸，新写时顺手用`x`便于统一搜索，不为历史格式不同返工。尺寸以实际上传文件为准，未要求的尺寸无需为了Tag专门适配。

例如一张需求为ja、300×600的Dementia Test译图，可以使用：

```json
["ja", "300x600", "Dementia Test", "SHE-20261111-025"]
```

这是示例，不是固定模板。没有可信产品名时不猜补；日期、设计师、二创归属、共享部门等已有专门字段，不要求再复制成Tag。语言别名和大小写不单独构成不合格，也不为了凑模板增加标签。

## 上传和续办

新素材在官方入库工具的`tags`字段带上标签。已有素材缺少有用标签时，保留原标签，通过当前官方支持的追加方式补齐；明显误标则核清后修正。补Tag可直接改标签并读回确认；是否重新上传或入库以需求面板交付需要为准，R2中有重复对象不构成限制。

主控交接和上传终核时顺带检查语言Tag及明确尺寸是否方便查找。有缺项沿原需求会话补齐，不把标签规范升级为复杂评分或额外审批。已完成历史需求不因本次规范重新制作或批量改标签，后续处理到对应素材时再按需补齐。

2026-11-11通过官方素材库只读抽样及视频主控聊天核对，样本限当前可见范围，不代表全库统一标准：

- 其他近期图片样本有`en`、`spotify`，大按钮样本有`EN`、`US`、`demenz`等，说明现有习惯主要围绕语言和产品词，写法并不完全一致。
- 视频主控“配置 Fireplay 轮询并续办任务”（聊天`01a1bffe-1cca-7293-a615-90b51f080f89`）要求语言及一至两个产品词；实际抽样`KEY-20261110-032-tr`的标签为`tr`、`二创`、`agent`，不能把流程要求当成所有历史素材都已补齐。
