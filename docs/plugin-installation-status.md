## 本轮修复

原版本依赖固定端口的独立iframe，项目服务关闭或宿主地址改变时显示空白；控件引用了不存在的主题变量，界面生硬。

当前已改成宿主React原生界面：左侧原图归组、中央图片对照和语言/版本选择、右侧整图意见、下方紧凑区域表。关联会话与发送预览放入次级折叠区。使用当前宿主公开的深浅主题变量。

浏览器通过当前DSH同源 `/local-image-review/` 获取数据，Host使用DSH原始请求认证、Origin/Host和CSRF检查，再连接实际项目Python服务。服务关闭时自动启动，仅停止插件自己创建的进程。Python token不发到浏览器。不再需要人工配置 `--dsh-origin`。

实际DSH路由回归另发现prefix路径不能带尾斜杠（按路径段匹配），已在 `route-host.js` 修正并写入真实HTTP回归测试。

## 给“工作台”的接续

安装与空白连接问题已由协助台解决，不必再重复安装、切Creator或认证排查。今后只维护 `plugins/image-review-workbench`，正式包名为 `@local/image-review-ui`。
