## 吸收的经验

1. **先认图组与尺寸**：本次三张完整原图×十语就是30张970×250。明确原生规格优先，不扩成七成员或套默认尺寸；通用规则继续由[图组与尺寸规划](../knowledge/methods/source-set-and-size-planning.md)维护。
2. **按图选择最小可靠路线**：低纹理浅底横幅可以复用逐来源审核过的背景，右侧食物/图形和A–E保留原像素，再独立排十语文字。不把此路线推广到摄影纹理或遮挡背景。
3. **语义审核细到短按钮**：法语初稿遗漏“now”，补回“maintenant”后换新JPEG并重新绑定审核；同一主题的图也要逐图识读问题，不能复制另一张图的提问。
4. **最终字节才是交付对象**：最终JPEG须实际看图、量尺寸/字节并哈希；历史PNG和新版JPEG分别记录，平台读回文件与当前审核字节一致才记交付核验。
5. **测试也需要可移植证据**：已有调度测试依赖被忽略的生产记录，现抽取有限固定样本供离线回归，仍保留生产清单的SHA门禁，不让测试样本成为新需求授权。
6. **状态分开记录**：UI已接收、自审通过、上传绑定、fresh读回、风险审批和用户验收分别记录。案例风险仍pending、业务状态仍not_started、用户验收未记录。
