## 制作方法

1. 看真实来源图，区分品牌、产品名、文案、数字条件和可保留信息；规范化图像后使用统一坐标，不猜不可辨文字。
2. 按区域实际条件选路：纯色去字、源像素局部重建、矢量容器重建或真实可用的图像编辑。纯文生图不能冒充参考图编辑。
3. 先单独审核无字背景，再制作透明目标字层，最后合成和适配。共享底图及保护区通过SHA复用，语义区与实际字层逐区对应。
4. 文字与容器一起设计，检查字重、黑白面积、行宽、字距、材质、透视与层级；复杂方竖适配重排独立层，不拉伸整张广告或重复贴图。
5. 先看全图和正常展示尺度，再看100%和必要局部。自然背景补全、合理重排与非识别性装饰差异可接受；错金额、漏条件、错误身份、主体畸形、裁字或明显接缝必须修复。

评分维度为语义30、画面流畅25、整体一致20、可读15、构图10；总分至少80并满足所有底线、实际尺寸/字节/格式及内容硬检查后提交。评分是实际视觉判断，程序只负责验证输入与计算；不得用高总分抵消底线失败。

## 可复用工程能力

- `material-size-plan`与`material-size-validate`冻结实际矩阵，验证来源、语言、明确成员、像素、文件格式和字节限制。
- `delivery-score`将提交门禁与续作动作分开；有正确事实但排错字可在两轮内返工，未知原文或身份依据则挂起，不伪造事实。
- `delivery-next`按当前证据返回制作、复审、返工及各发布步骤；损坏或过期的成员回退到相应动作。
- `delivery-gate`仅导出当前已审合格成员的真实输出SHA；部分可交付不等于整个需求完成。
- 本地多语任务、可配置字效、字形覆盖检查、版本化产物、视觉差异记录和审阅工具连同示例配套保存。示例使用相对路径和可再分发字体子集，保留历史失败与用户反馈。
