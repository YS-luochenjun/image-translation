# 单图片翻译审阅台

项目工作台已完成，读取真实制作记录，支持图片归组、语言/版本切换、紧凑逐区审阅和追加反馈。正式 DSH 插件包也已完成；尚未安装到当前 DSH，宿主内验收交由 Creator 会话接续，见 [Creator 交接](creator-handoff.md)。

## 打开工作台

双击项目根目录的 [打开审阅台.cmd](../打开审阅台.cmd)，或运行：

```powershell
python bin/it.py review-desk --open
```

默认地址 <http://127.0.0.1:8765/>。当前已在此地址启动新版服务，允许当前 DSH <http://127.0.0.1:64626> 嵌入。启动窗口需保持运行，Ctrl+C 关闭。双击入口自动寻找 `IMAGE_TRANSLATOR_PYTHON`、项目虚拟环境、Harness 自带 Python、PATH 中的 Python。

服务重启后用于 DSH 嵌入时运行：

```powershell
.\打开审阅台.cmd --dsh-origin http://127.0.0.1:64626
```

或 `python bin/it.py review-desk --dsh-origin http://127.0.0.1:64626`。DSH 地址变化时使用实际来源。默认不传参数禁止嵌入；显式来源与已有服务不一致时会报错，关闭旧服务后重新启动。只复用同一应用、同一项目的服务；其他程序占用端口时明确失败。

## 审阅流程

1. 左侧按原图 SHA256 归组，展开一张图，选择语言；顶部切换该语言的制作版本。归组采用源文件字节身份，重新编码的相似图可能分成两组。缺少来源或语言的记录不会猜测合并。
2. 用双图、滑杆或单图查看原图与译图。可切换无字背景、文字层和原图，使用原尺寸查看细节。
3. 下方是紧凑区域表格，每行显示编号、原文、译文和结论。点击编号展开完整内容、制作说明和备注；点击图片区域也可定位对应行。
4. 筛选全部、待处理、需要修改的区域；“本页全部认可”只作用于当前筛选结果，保留已填备注。所有区域操作仍需保存。
5. 填整图说明与结论，点击“保存审阅”。整图认可不能与区域修改要求冲突；没有成图不能认可。切换图片、语言、版本或刷新前会提示未保存草稿。
6. 需要返工时点击“复制返工指令”。它读取当前版本最新已保存反馈；剪贴板不可用时可在展开文本框手动复制。无当前意见或最新为认可时，返回明确的无需返工说明。

保存反馈不会自动修改图片。当前独立页面可以复制指令；正式插件安装后，支持选择本项目会话、确认目标、预览指令并显式发送。

## 版本和反馈身份

每条记录含任务 ID、时间、用户署名、整图/区域结论与原话，以及源图、输出、语义清单的 SHA256。缺少语义清单绑定的旧分层记录改为绑定制作配置，并明确显示“配置指纹”。

保存前重新读取三个哈希；文件发生变化返回 409，保留草稿供处理。返工指令只使用与当前任务及三项哈希一致的最新反馈；最新认可覆盖此前的返工要求。历史意见仍可查阅，不升级旧审核结论。

反馈追加到 `.review-desk/feedback/<任务ID的SHA256>.jsonl`，不覆盖 Agent 审核、技术门禁或制作文件。署名是用户填写的名字，不是身份认证。

## DSH 插件

包位于 [plugins/image-review-desk](../plugins/image-review-desk/README.md)，使用该安装版本官方的 `sidebar.panellist`、`main` 和会话 prompt API，限定当前项目目录与项目指纹。其他项目不会挂载此项目的工作台。

派发流程是：选择关联会话 → 确认目标 → 读取已保存意见 → 查看完整指令 → 点击发送。发送前再次核对任务、反馈、三个哈希和会话；未保存草稿、认可记录或过期指令不会派发。失败保留预览，重试复用请求 ID。接收成功表示会话已排队，不代表图片返工完成。

插件尚未在当前 DSH 安装、渲染或实际派发验收。安装状态不能以包存在或 VM 测试代替。Creator 可直接按 [交接文档](creator-handoff.md) 完成正式安装和宿主验收。

## 本机边界

服务只监听 `127.0.0.1`，校验 Host、Origin、Fetch-Site 与随机请求令牌；图片只允许读取已发现任务引用的文件。嵌入来源只接受显式精确 loopback HTTP origin，来源例外只适用于 iframe 首页导航，API 继续拒绝跨源请求。父子页面通信同时核对 origin、窗口来源和版本，业务文本不作为执行指令。
