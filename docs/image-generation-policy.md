# 图片翻译的生成与去字路线

本规则适用于当前项目所有已交办的图片翻译需求。

## 当前授权

用户已明确授权已交办图片需求合理使用付费内容与工具，包括 KIE 和 GPT ImageGen。项目不设置逐单预算、生成次数或“先用便宜模型试试”的门槛；执行会话记录真实调用、费用、输入输出和工具回执即可。宿主工具自身的能力、付款、审批和权限边界仍然有效，项目规则不能绕过这些边界。

## 路线顺序

复杂摄影、人物或产品边缘、跨纹理文字、渐变光影、海浪、天空、树叶、道路灯轨和需要保留细节的去字，优先使用当前会话真实支持参考图编辑的 Codex ImageGen，或查询 KIE 后选择真实支持原图输入的编辑能力。编辑提示必须明确“只去除指定原文字，保持主体、品牌、构图、光照和非目标内容不变”，并在加入译文前单独审核无字底图。

OpenCV、Telea、局部采样和本地 LaMa 只能用于已经核实的平色小区域、辅助蒙版或确定性合成。它们不能作为复杂摄影的默认首选，也不能因为本地路线失败就要求用户提供无字原图、宣布需求阻塞或停在初稿。

纯文字生成接口只能产生设计参考；若工具不支持参考图输入，不能声称它完成了原图去字。无论模型返回成功与否，都必须实际打开源图、无字底图、独立字层和最终尺寸，检查主体保真、残字、暗带、糊化、接缝、字体效果和文字完整性。失败就换路线或局部重建，直到达到当前交付评分门槛；确有外部能力阻塞时，只挂起受影响成员并继续其他成员。

历史候选和失败试验保留作证据，不得被当前执行会话当作可交付版本复用。执行会话读取本文件后，直接沿当前有效授权继续制作、上传、入库、共享、需求绑定和 fresh 核验。

成员级冻结从官方上传成功回执开始，而不是等整组入库或 fresh 核验完成。后续质量讨论、ImageGen 与 KIE 路线切换、字体意见或整组补齐，只能作用于尚未成功上传的成员；已上传成员只允许做入库、归属、共享、绑定和 fresh 读取核验，禁止重制、替换、追加版本或重复上传。返工必须由用户明确提出，或由官方回执明确要求，并以新的修订记录处理。
