# 流程台

当前插件 `@local/image-review-ui@5.2.1`，通过官方 Plugin Manager 安装，宿主左侧入口为“流程台”（原图片审阅）。使用宿主 React、原生 Slots、主题及官方会话接口。

仅显示当前官方标题完整匹配需求编号的会话（如 `SHE-20261103-068`、`APC-20261023-008`）；普通会话和未关联历史隐藏，原始记录保留。先读取轻量会话索引，选中后才加载该会话的图，列表每2秒刷新、选中详情每4秒串行刷新。左侧切换需求会话，主区先展示输入、识别、翻译、背景、文字层、合成、检查、交付八组主要步骤，选中后仅一个结果区显示内容。相同哈希图片合并来源；交付用“成品 / 对比”页签切换，不再在顶部和节点详情重复铺图。未产生内容的制作节点不占位，原始节点事实保留在调试信息。

对话运行时，真实计划、明确阶段、关键结果及生产事件持续同步。尚未产生工作包的会话也显示当前步骤和显式任务计划；会话计划不会自动冒充图片制作完成。手动选择步骤不会被轮询切走。

可以打开原对话、向当前会话或所选步骤发送指令、请求继续、停止会话本轮运行。步骤指令携带原会话、原工作包/节点或计划事件ID和索引，通过官方 Remote 排队；已接收不代表步骤已完成。发送结果未知时保留同一冻结请求供显式重试，不自动重发。

保存结果与区域点评保留在“更多”内。点评和保存仍绑定当前产物字节；历史未关联工作包只读，明确关联后才允许写入。完整接入与边界见 [工作台说明](../../docs/workflow-desk.md)，原始节点见 [节点清单](../../docs/workflow-node-inventory.md)。
